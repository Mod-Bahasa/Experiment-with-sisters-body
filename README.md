# Experiment with Sisters Body (Indonesian Translation)

A fan-translated version of the simulation game. This project ports and translates the interface into casual Indonesian.

## Game Overview
* **Alternative Title:** Lakukan eksperimen dengan tubuh adikku
* **Original Developer:** TissuBox
* **Release Date:** May 1, 2022
* **Platform:** Android
* **Language:** Japanese (Original), Indonesian (Fan Translation)
* **Genre & Tags:** 18+, Simulation, Pixel Art, Animated
